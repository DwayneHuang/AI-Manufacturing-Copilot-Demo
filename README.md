# 🏭 AI Manufacturing Copilot Demo

面向制造业的智能生产与采购协同助手 Demo，采用 **ERP 确定性计算引擎 × 飞书交互体验 × 人工审批闭环** 架构，可一键部署至 **Streamlit Cloud**。

---

## 🌟 核心特性与架构

```
┌────────────────────────────────────────────────────────────────────────┐
│                        AI Manufacturing Copilot                        │
├───────────────────────────────────┬────────────────────────────────────┤
│       左侧：ERP Dashboard (3)       │       右侧：飞书 AI 助手 (2)        │
│  - 🏭 生产计划管理 (可调排产)      │  - 🤖 飞书视觉风格交互入口          │
│  - 📋 BOM 物料清单展开与单台成本  │  - ⚡ 快捷指令 (查BOM/查库存/缺口) │
│  - 📦 实时库存总览与告警过滤      │  - 💬 自然语言查询与改数            │
│  - ⚠️ 确定性物料缺口智能测算      │  - 🛡️ 采购申请生成与状态提示        │
│  - 🛒 采购建议与人工审批卡片      │                                    │
├───────────────────────────────────┴────────────────────────────────────┤
│       🔄 统一数据仓库 (ERPDataStore) — 双向实时数据同步               │
├───────────────────────────────────┬────────────────────────────────────┤
│      确定性 ERP Tools (FastAPI)   │         LLM + Agent 核心           │
│  - BOM 展开与层级成本汇总         │  - Gemini 2.0 Flash Function Call  │
│  - 需求与物料缺口计算             │  - 自动任务规划与工具路由          │
│  - 供应商 MOQ 与交期向上取整      │  - 优雅降级：确定性规则引擎        │
│  - 人工审批安全保护 (草案机制)    │                                    │
└───────────────────────────────────┴────────────────────────────────────┘
```

1. **左右分栏布局**：
   - **左侧 ERP 看板**：展示生产计划、BOM 物料清单、实时库存状态、物料缺口分析、采购管理。
   - **右侧飞书工作台**：模拟飞书聊天交互界面，作为 AI Agent 的自然语言交互入口。
2. **确定性 ERP Tools (Python / FastAPI)**：
   - 负责 BOM 展开、库存查询、物料需求及缺口计算、采购建议等业务逻辑，确保计算结果精准、可追溯、可验证。
3. **LLM + Agent 智能体**：
   - 基于 Google Gemini 2.0 Flash + Function Calling，负责自然语言理解、意图识别与工具规划。
   - 内置**确定性规则引擎**作为离线保障，即使未配置 API Key 亦可完美流畅体验所有功能。
4. **模拟 ERP API 数据体系**：
   - 提供 3 款智能穿戴/音频产品、22 种主辅物料、完整多级 BOM 结构、多仓库库存分布及 7 家核心供应商档案。
5. **飞书机器人集成场景**：
   - 飞书专属主题配色、会话流转、时间戳、快捷业务 Action 芯片。
6. **人工审批机制 (Human-in-the-Loop)**：
   - Agent 仅能创建**采购申请草案 (Draft)**，必须由业务人员在看板中点击【批准】或在对话中输入【批准 单号】后方可正式生效，防止 AI 越权下单。
7. **双向实时数据同步**：
   - 左右两侧共享同一内存数据源，不论在左侧表单修改产量/库存，还是在右侧聊天框用自然语言修改，全局计算结果毫秒级联动更新。

## 🚀 一键部署到 Streamlit Cloud

1. 将本仓库代码推送到 GitHub。
2. 登录 [share.streamlit.io](https://share.streamlit.io/)，点击 **New app**。
3. 选择仓库、分支，主入口文件填写：`app.py`。
4. （可选）在 **Advanced settings -> Secrets** 中填入 Gemini API Key：
   ```toml
   GOOGLE_API_KEY = "你的_GEMINI_API_KEY"
   ```
   *注：未配置密钥时，系统自动运行于确定性规则引擎模式，所有业务功能与双向同步同样 100% 正常可用！*
5. 点击 **Deploy** 即可上线演示！

## 💻 本地运行指南

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行 Streamlit 应用

```bash
streamlit run app.py
```
浏览器打开 `http://localhost:8501` 即可体验。

### 3. （可选）独立启动 FastAPI 服务

如需查看 Swagger API 交互文档或供外部系统调用：

```bash
python run_api.py
```
- Swagger 接口文档：`http://localhost:8000/docs`
- ReDoc 接口文档：`http://localhost:8000/redoc`

## 📋 演示操作脚本 (Demo Script)

在评审或客户演示时，可按以下流程体验：

| 步骤 | 演示操作 | 预期效果 |
|:---:|---|---|
| **1** | 点击右侧快捷按钮 **【📋 查BOM】** 或输入 `查看智能手表的BOM` | AI 展示智能手表 X1 Pro 的 10 种零配件用量及单台成本 |
| **2** | 点击右侧快捷按钮 **【📦 查库存】** 或输入 `查询M001库存` | 查看 AMOLED 屏幕当前库存 300 块、安全库存 100 块 |
| **3** | 点击 **【⚠️ 算缺口】** 或输入 `分析当前物料缺口` | 计算当前生产计划下的物料短缺清单与预估补货成本 |
| **4** | 输入 `把M001库存改为50` (模拟屏幕缺货) | 左侧库存看板与缺口分析实时联动刷新，M001 标记为紧急缺料 |
| **5** | 输入 `创建采购申请单` | 生成采购申请单草案 `PO-YYYYMMDD-001`，标记为 ⏳ 待审批 |
| **6** | 在左侧「采购管理」点击【✅ 批准】或右侧输入 `批准 PO-20261118-001` | 申请单转为已批准状态，完成人工核准闭环 |
| **7** | 在左侧「生产计划」修改智能手环产量为 1500 台 | 右侧询问 `分析物料缺口` 时，即刻呈现新的计算结果 |
| **8** | 点击侧边栏 **【🔄 重置所有演示数据】** | 一键恢复系统初始状态，方便下一轮演示 |
